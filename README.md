# Session AD162 - Everything new - Try out the latest and greatest CAP features

## Description

This repository contains the material for the SAP TechEd 2026 session called AD162 - Everything new - Try out the latest and greatest CAP features.  

## Overview

This session introduces attendees to try out new CAP features yourself! Start with guided AI-driven app development and extend it with:
- Declarative Constraints
- Status Transition Flows
- using the cds repl
- extensibility with CDS-Oyster
- HCQL, CAP's native query-over-HTTP protocol
- and more

## Requirements

- **Git** and **Visual Studio Code** (pre-installed on the TechEd notebook)
- **Claude Code**, pre-configured on the TechEd notebook
- **Node.js** 24.x (LTS) and **npm**
- **`@sap/cds-dk`** 10.1 or later (installed in Exercise 0)

| Component | Version |
|---|---|
| Node.js | 24.x (LTS) |
| `@sap/cds-dk` (global CLI) | 10.1 |
| `@sap/cds` (runtime) | ^10 |
| `@cap-js/sqlite` | ^3 |
| `@cap-js/cds-test` | ^1 |
| CAP skills | public `github.com/capire/skills` (session release) |
| CAP MCP docs server | `@cap-js/mcp-server` (`cds-mcp`) |
| AI tool | Claude Code |
